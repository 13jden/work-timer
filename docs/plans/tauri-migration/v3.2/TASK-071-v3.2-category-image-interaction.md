# TASK-071 · v3.2 分类自定义图片交互优化

> **状态**：🧩 实现中，待验收
> **分支**：`main`
> **前置**：TASK-070（分类自定义图片初版）

---

## 目标

优化 TASK-070 的分类自定义图片交互，三个具体改动：

1. **「自定义」按钮移到「图标」标签右侧** —— 不再另起一个独立字段块。
2. **不向用户解释压缩过程** —— 压缩是实现细节，用户要的是「选一张图当图标」。
3. **选图后不需要背景色** —— 图片直接铺满分类框，颜色选择整块隐藏。

---

## 一、「自定义」按钮贴在「图标」标签右侧

### 之前

「图标」是一个字段块（标签 + 65 个线稿图标网格），「自定义图片」是**另一个独立字段块**（虚线框 + 选图按钮 + 说明文字）。

### 现在

「自定义」变成一个药丸按钮，贴在「图标」标签行的右侧：

```
图标                              [🖼 自定义]
┌──────────────────────────────┐
│  (65 个线稿图标分组网格)      │
└──────────────────────────────┘
```

选中自定义图后，按钮下方出现缩略图 + 「移除」。

### 为什么

线稿图标和自定义图片是**同一个选择动作的两种来源**。拆成两个字段块，用户会以为是两件事，
得先想清楚「我要用哪个」，再往下走。合成一行之后，选择器就是一个整体。

### 结构改动

```tsx
<div className={styles.fieldLabelRow}>          // 新增：flex + space-between
  <label className={styles.fieldLabel}>图标</label>
  <button className={styles.customPickBtn} onClick={...}>
    <ImageSquare size={13} /> 自定义
  </button>
</div>
```

## 二、不解释压缩过程

删掉了：

- `customImageHint`（「已选好，会自动压缩到 256px」/「从相册选一张图当分类图标」）
- `customImageRow`（整个虚线框容器）
- `customImagePick` / `customImageThumb` / `customImageRemove` 三个样式

**保留**：压缩失败时的错误提示（`这个格式不支持，换张 JPG / PNG 试试`）—— 那是失败反馈，不是流程解释。

压缩本身没变：还是 `compressImage(file, 256, 0.8)`（最长边 256px，JPEG 0.8）。

**为什么**：用户选图时只关心「这张图能不能用」。告诉他「会自动压缩到 256px」既不解决任何问题，
还让人以为压缩会影响画质、需要权衡。做了就做了，不必邀功。

## 三、选图后不需要背景色，图片铺满分类框

### 颜色选择整块隐藏

```tsx
{!hasCustomImage && (
  <div className={styles.field}>
    <label className={styles.fieldLabel}>颜色</label>
    <div className={styles.colorGrid}>...</div>
  </div>
)}
```

选了自定义图 → 颜色字段消失；移除图片 → 颜色字段回来。

### 图片铺满分类框

`CategoryIcon` 增加 `fill` 模式：

| 模式 | 行为 | 用在哪 |
|---|---|---|
| `fill`（默认） | 宽高各 100%，`border-radius: inherit`，`object-fit: cover` | 图标方块类容器（12 处） |
| `fill={false}` | 按 `size` 渲染小方块 | 无固定尺寸的容器（记账分类网格、行内文字流） |

图片铺满 → 父容器的背景色被完全盖住 → **背景色确实不再需要了**。
这也让「颜色字段隐藏」不只是少一个 UI 元素，而是逻辑自洽：颜色本来只是给图标垫底的。

### 配套改动

- **10 个图标方块容器加 `overflow: hidden`** —— 让图片的圆角裁切生效。
  圆角靠 `border-radius: inherit` 跟随父容器，所以图片的形状 = 分类框的形状。
- **`AddCategoryModal` 预览卡重构** —— 原来名字在色块**内部**（96×96 色块 + 内部图标 + 内部文字）。
  现在色块是纯图形（84×84），名字移到色块**下方** —— 图片要铺满色块，里面就不能再塞文字。
- **`AddRecordModal` / `JourneyRecordPicker` 用 `fill={false}`** —— 这两处的容器没有确定尺寸
  （`inline-flex` 无宽高 / 行内文字流），`width: 100%` 会塌成 0。
