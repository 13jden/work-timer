统计参数设计

周 / 月视图共用的参数口径，以及非工作日处理规则。

核心参数 日 / 周 / 月 通用

参数定义非工作日规则
总工时Σ 班次时长仅累加工作日
午休扣除Σ 午休时长（多段午休合计）仅累加工作日
摸鱼扣除Σ 摸鱼时长仅累加工作日
加班Σ 加班补偿时长仅累加工作日
净工时总工时 − 午休 − 摸鱼 + 加班—
累计已赚Σ 每日已赚—
净时薪累计已赚 ÷ 净工时自然只含工作日
摸鱼总薪资摸鱼时长 × 基础时薪—

周 / 月专属参数 非工作日不参与平均

参数定义展示位置
日均净工时净工时 ÷ 工作日天数（不除以自然日）双栏卡右侧，附「非工作日不参与平均」小字
工作日 / 休息日区间内计数（含自定义休息日）月视图双栏卡「出勤 22 天 · 休 8 天」
时长去向有效 / 摸鱼 / 加班 三段占比（加班按补偿时长计入）堆叠条 + 三列图标，参考健康 app 活动占比
选中日净工时点击柱子切换大数字（周视图）顶部大数字 + 柱高亮

非工作日视觉与交互规则

图表：非工作日的柱子渲染为空心虚线圆点（不占高度），X 轴标签显示「休」，一眼可辨。
平均：日均净工时、净时薪的分母均为工作日天数；自定义休息日（设置里配置的）同样排除。
交互：点击空心圆点不切换大数字，仅 toast 提示「休息日 · 无工时数据」。
区间切换：顶部「▾」弹出区间选择器；周视图左右箭头切换上/下周，月视图切换上/下月。
未来日期：当月未到的日期柱子以 40% 透明度占位，不参与累计与平均。
