## 2. 范围与设计

### 2.1 统计页（替换 STATS 占位，tab 1）

**页面结构（自上而下）**：

```
┌────────────────────────────┐
│ [日 | 月 | 年]  视图切换     │  ← 复用 SegmentedControl
│ [支出 | 收入]   类型切换     │  ← 复用 SegmentedControl
├────────────────────────────┤
│ 汇总条：本期总支出/总收入     │
│        + 环比上期 ±%        │
├────────────────────────────┤
│ 图表区（月/年视图）          │
│  或 记录列表（日视图）       │
├────────────────────────────┤
│ 分类排行（月/年视图）        │
└────────────────────────────┘
```

**三视图行为**：

| 视图 | 内容 | 交互 |
|---|---|---|
| 日 | 选中日的记录列表（纯列表，无图表）：分类图标 + 分类名 + 备注 + 金额 | 顶部日期左右切换（复用日视图日期切换样式） |
| 月 | 当月每日收/支双柱柱状图 + 分类排行条形列表 | 点击某天柱子 → 切到日视图并定位该天 |
| 年 | 全年 12 个月收/支双柱柱状图 + 分类排行条形列表 | 点击某月柱子 → 切到月视图并定位该月 |

**分类排行**：

- 按所选类型（支出/收入）聚合本期各分类总额，降序
- 条形列表：分类图标 + 名称 + 条形进度（相对最大分类占比）+ 金额 + 占比 %
- 点击某分类 → 进入分类记录页（见 2.3）

**图表实现**：

- 纯 div + CSS 实现柱状图（不引图表库），高度按最大值归一化
- 收/支双柱并排：支出柱用 `--danger` 系、收入柱用 `--accent` 系（跟随主题变量）
- 月视图 31 根柱过密时：横向滚动 + 柱宽自适应，保证可读

### 2.2 记账日历（替换 CAL 占位，tab 2）

**页面结构**：

```
┌────────────────────────────┐
│ ‹ 2026年9月 ›   月切换      │
├────────────────────────────┤
│ 一  二  三  四  五  六  日   │
│ ┌──┐┌──┐┌──┐ ...           │
│ │ 1││ 2││ 3│               │
│ │-32││+1││  │  每日净额      │
│ └──┘└──┘└──┘               │
├────────────────────────────┤
│ 本月小结：支出 X / 收入 Y    │
└────────────────────────────┘
```

- 月历格子：每格显示日期 + 当日净额（收-支），支出为主时红色系、收入为主时绿色系、无记录不显示金额
- 今天的格子高亮描边（主题 accent）
- 月份左右切换（复用计时日历的交互习惯，但**新建组件**，不动 `CalendarPage`）
- 点击某天 → 日详情弹窗

**日详情弹窗**（底部半屏，复用 AddRecordModal 的 sheet 结构）：

- 头部：日期 + 当日总支出/收入
- 记录列表：分类图标 + 名称 + 备注 + 金额（点击可编辑，复用 `RecordActionSheet`）
- 底部「+ 记一笔」→ 打开 AddRecordModal 并预填该日期

### 2.3 分类记录页（新页面组件）

- 入口：统计页分类排行点击 / `CategoryDetailPanel` 内「查看全部记录」
- 内容：该分类全部记录按时间倒序，按月分组展示；顶部显示分类大图标 + 名称 + 累计金额
- 支持月份筛选（默认全部）

## 3. 数据与聚合逻辑

新增 `src/lib/accounting/stats.ts` 纯函数（**必须有单测**）：

| 函数 | 说明 |
|---|---|
| `filterByRange(records, startKey, endKey)` | 按 dateKey 范围过滤 |
| `aggregateByDay(records)` | → `Map<dateKey, { income, expense }>` |
| `aggregateByMonth(records)` | → `Map<monthKey, { income, expense }>` |
| `aggregateByCategory(records, type)` | → `Array<{ categoryId, total, percent }>` 降序 |
| `sumRecords(records)` | 总收入 / 总支出 / 净额 |

- 未分类记录（`isUncategorized=true`）在排行中归入「未分类」虚拟分类展示
- 虚拟池记录（`poolStatus='virtual'`）本期**不参与统计**（池机制 v2.3 才启用，预留开关参数）
