## 交互设计

### 模式切换
- **首页下滑** → 进入「记账模式」，原位淡入替换（crossfade 250ms）
- **首页上滑** → 返回「计时模式」，原位淡出
- **触发阈值**：60px
- **状态保留**：两模式各自滚动位置互不干扰

### 快速记录
```
┌────────────────────────────┐
│ [¥ 50.00]      [支出 ▼] ＋ │
└────────────────────────────┘
```
- 金额输入框（必填）
- 类型切换（支出 / 收入）
- +按钮 → 提交

### 完整添加弹窗
- 底部半屏 Modal
- 金额（大字号）
- 类型切换（支出 / 收入）
- 分类选择（chip 列表）
- 备注（输入框）
- 日期（默认今天，可改）
- 提交按钮
