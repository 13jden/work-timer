### C · MINE 页集成（T-405）

### D · 池收入/支出方向（T-406）

- `PoolConfig.direction`：收入池逐日生成收入记录（虚拟到账）/ 支出池生成支出记录（虚拟均摊）
- 建池弹窗方向开关，分类选择按方向过滤；收入池卡片显示到账进度与未到账金额

### E · 拖拽归入账户（T-408）

- 统计页日视图 dnd-kit：整行拖动 → 底部账户 dock → 松手归入；行内账户标签，未归入红色虚线标记
- 余额随 `updateRecord` 自动迁移（换账户时旧账户回退 + 新账户计入）

### F · 虚拟资产分解（T-409）

- 总资产卡 = 实际资产 + 预付未消耗（淡红）+ 已赚未到账（淡绿）
- 未归入记录与先用后付「未支付」同虚线框调整项展示；统计页池逐日记录标「虚拟到账 / 虚拟均摊」
- 纯函数 `calcVirtualAssets`（`src/lib/accounting/virtual.ts`）+ 13 条单测

### G · 池自动退休 + 记录溯源 + 记录编辑（T-410）

- **记录周期快照**：均摊记录生成时即存 `poolCycleStart/End`（几号到几号）、`poolCycleTotal`（均摊总额）、`poolName`（池名），池删除后仍可溯源；认领记录同样快照所属周期
- **虚拟变实际**：周期认领满额时，该周期全部均摊记录回写 `poolSettledAt/Amount`（真实入账/支出的时间与金额），行内标「已关联池」；存量记录由 `syncPoolCycles` 回补
- **池自动移除**：`retireFinishedPools` —— 满额且周期已过的均摊池自动删除，只删池配置与周期元数据，均摊记录与认领记录全部保留；认领 / 启动同步时自动触发
- **列表与统计分离**：统计页日视图用 `listableRecords` 展示认领付款记录（「已关联池 · 不计统计」标记），汇总 / 图表仍走 `visibleRecords`，不重复计算
- **记录点开编辑**：日视图记录行点击打开编辑弹窗（金额 / 分类 / 账户 / 备注），保存自动清除未分类状态；拖拽启动后抑制误触点击
- **编辑弹窗池只读信息**：均摊记录展示均摊周期 / 周期总额 / 实际关联时间金额；认领记录展示关联周期快照
- **余额守护**：`recordAffectsBalance` 判定记录是否真实动余额 —— 池逐日均摊记录与存量虚拟预扣编辑/删除不迁移余额，避免凭空增减
